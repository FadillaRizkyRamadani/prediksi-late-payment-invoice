# Prediksi Keterlambatan Pembayaran Invoice dengan Machine Learning

Studi kasus sederhana menggunakan Python dan algoritma Machine Learning (Random Forest) untuk memprediksi apakah suatu tagihan/invoice akan terlambat dibayar oleh pelanggan atau tidak.

## 🚀 Fitur Utama
* Pembuatan dataset simulasi transaksi B2B.
* Analisis fitur (jumlah tagihan, riwayat keterlambatan pelanggan, tenor kredit).
* Evaluasi performa model menggunakan Accuracy dan Confusion Matrix.
